### My Development Workflow

The application is being developed through an **AI-assisted engineering workflow**.

I define the requirements, expected behavior, business rules, and validation criteria, then use AI coding tools inside VS Code to assist with implementation.

```text
Problem Definition
       ↓
Requirements & Rules
       ↓
AI-Assisted Implementation
       ↓
Automated Tests
       ↓
Manual / Browser Validation
       ↓
Debugging & Review
       ↓
Refinement
       ↓
Git + CI Validation
```

The goal is not simply to generate code.

The goal is to **define the right system, guide the implementation, detect failures, validate behavior, and iteratively improve the application until it works correctly**.

## ⚙️ How I Approach AI-Assisted Development

I use AI as a **development multiplier**, while keeping problem definition, requirements, validation, and decision-making human-controlled.

```mermaid
flowchart LR
    A[Understand Problem] --> B[Define Requirements]
    B --> C[Direct AI Implementation]
    C --> D[Run Tests]
    D --> E{Correct?}
    E -->|No| F[Debug & Refine]
    F --> C
    E -->|Yes| G[Validate Behaviour]
    G --> H[Commit & Iterate]
```

My focus is not:

```text
"AI wrote the code."
```

My focus is:

```text
Can I define the right system,
guide the implementation,
detect problems,
validate the result,
and improve it?
```
